PROYECTO 02

Reloj con alarmas

Descripción

Aplicación web que muestra un reloj con la hora actual y permite administrar una lista de alarmas. El reloj revisa cada segundo si hay una alarma programada para ese momento y, cuando la encuentra, cambia de color y emite un sonido para avisar al usuario.

Qué hace

Reloj en tiempo real

Muestra la hora y el día de la semana, actualizados cada segundo.

Agregar alarmas

El usuario elige el día y la hora, y la alarma queda visible en una lista.

Editar y borrar

Cada alarma de la lista se puede modificar o eliminar.

Aviso de alarma

Al llegar la hora, el reloj cambia de color y suena hasta que se detiene.

Alarmas guardadas

Las alarmas se conservan en el navegador aunque se recargue la página.

Tecnologías

  • HTML5
  • CSS3
  • JavaScript
  • Web Audio API
  • localStorage

Mi participación

Proyecto individual. Desarrollé la estructura, los estilos y la lógica en JavaScript: el reloj, la verificación de alarmas, el sonido y el manejo de la lista (agregar, editar y borrar).
